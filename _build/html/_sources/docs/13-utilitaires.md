# Utilitaires

## Script de Compression (`zipper.py`)

Ce script Python permet de compresser l'intégralité du dossier `includes_sassemeV1` dans une archive `.zip`. Cette archive est utilisée pour fournir une version "release" des données finales, téléchargeable directement depuis l'introduction de ce livre.

Le script exclut automatiquement les fichiers `.gitkeep` pour ne pas inclure de fichiers inutiles dans l'archive.
