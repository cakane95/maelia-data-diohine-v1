## 1. Objectif

Ce document décrit le processus de copie du fichier `joursParMois.csv` vers son emplacement final dans l'arborescence de MAELIA.

## 2. Méthodologie

Le fichier `joursParMois.csv` est une donnée d'entrée fournie. Ce processus ne modifie pas le fichier mais assure simplement qu'il est placé dans le bon dossier (`includes_sassemeV1/modeleCommun/date/`) pour la simulation. Le fichier original sera stocké dans le dossier `data/commun/csv/raw/`.

## 3. Fichiers Source et Cible

* **Fichier en Entrée :** `data/commun/csv/raw/joursParMois.csv`
* **Fichier en Sortie :** `includes_sassemeV1/modeleCommun/date/joursParMois.csv`
